Cleanup Orphaned Files

Warning: This will permanently delete orphaned files including:
  • Files with empty media_url or attachment fields
  • Duplicate "download image" files (keeps only one)
  • Gemini generated image fragments
  • Generic numbered files (likely fragments)
  • Files with generic names like "image", "download", "untitled"
  • Very small files (< 1KB) that are likely fragments
  • Duplicate files with same title and size

This enhanced cleanup removes orphaned file fragments that have valid URLs but are duplicates or generated files that clutter the file manager.
